# 编织者 v1.0

> 一个调用 AI 接口、批量生成图片的 Windows 桌面小工具（Python + tkinter + PyInstaller）。

![license](https://img.shields.io/badge/license-MIT-green)
![platform](https://img.shields.io/badge/platform-Windows%2010%2F11-lightgrey)

---

## 一、这是什么

**编织者** 帮你把一段段文字提示词（prompt）丢给 AI 画图接口，自动生成一批图片。
它适合这样的场景：

- 做卡牌 / 立绘 / 设定图，需要一次性产出很多张；
- 想用「参考图」让 AI 模仿某个角色或画风；
- 不想记接口参数，只想填好 Key、粘贴提示词就出图。

软件内置了「硅基流动（SiliconFlow）」适配器，并预留了 OpenAI 兼容 / Stability 等平台的接入位。

---

## 二、功能特性

| 能力 | 说明 |
|------|------|
| 📦 批量生成 | 拖入一个 `.txt` 文本文件，每行一条提示词，自动逐张生成 |
| 🎨 单个生成 | 一次画一张，可填画风、上传参考图 |
| 🖼️ 图生图 | 支持「参考图」的模型可用单张模式上传参考图生成 |
| 🏷️ 画风前缀 | 默认自动给卡名套上「奇幻卡牌插画，精美」风格（可改） |
| 🕘 模型历史 | 每个平台记住用过的模型名，下拉可滚动选择 |
| 🔌 测试连接 | 可选「完整测试 / 仅格式检查」两种方式验证配置 |
| ⚙️ 多平台 | 硅基流动开箱即用；其他 OpenAI 兼容平台自行填 URL |

> ⚠️ **图生图模型只支持「单个生成」**：批量模式下遇到图生图模型会直接拦截并提示；
> 若模型是「参考图兼容」模式（文生图 + 图生图），则批量也可用（按文生图处理）。

## 三、下载与安装

1. 打开本仓库的 **Releases** 页面，下载最新版本的 `编织者.zip`；
2. 解压到任意文件夹（路径不要含中文/空格最佳）；
3. 双击 `编织者.exe` 即可运行，**无需安装 Python**。

> 生成的图片默认保存在程序同级的 `generated_cards/` 文件夹里。

## 四、使用方法

### 第 1 步：首次配置（填 API Key）

首次打开会弹出配置框，需要填写：

- **平台**：选「硅基流动」会自动填好接口地址，不用手抄；
- **API Key**：在你使用的 AI 平台后台自己注册获取（密钥只存在你本机，软件不上传）；
- **模型**：填你要用的模型名（例如 `Kwai-Kolors/Kolors`）；用过的模型会出现在「模型历史」里方便下次选。

填完点「保存」即可进入主界面。

### 第 2 步：选生成方式

主界面有两个入口：

- **📦 批量生成**：适合大量出图；
- **🎨 单个生成**：适合精修一张，或图生图。

### 第 3 种：批量生成怎么用

1. 准备一个 `.txt`，**每行一条提示词**，例如：

   ```
   红发少女，星空背景，手持长剑
   机械天使，废墟城市，黄昏光线
   ```

2. 在批量页把 `.txt` 拖进去（或点按钮选择）；
3. 可填「画风」（留空则用默认「奇幻卡牌插画，精美」）；
4. 点「开始生成」，进度条实时更新，完成后弹出成功/失败统计。

### 第 4 种：单个生成 / 图生图怎么用

1. 填提示词；
2. 若当前模型支持参考图，会出现「选择参考图」区域：
   - **图生图模型**：必须上传一张参考图；
   - **参考图兼容模型**：参考图可选（不上传就按纯文生图）；
3. 点「生成」即可。

### 测试连接

在「设置 → AI 调用」里点「测试连接」会让你选方式：

- **完整测试**：真正发一次请求，会消耗少量额度；
- **仅格式检查**：只校验 Key / URL / 模型格式是否填对，不花钱。
